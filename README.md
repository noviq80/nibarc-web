# nibarc-web

The Nibarc company site, with the Nexora product site mounted at `/nexora/`.
Static HTML generated by two small Python scripts — no framework, no build step
on Netlify.

## Layout

```
netlify.toml        Netlify config. publish = "site"
src/build_nibarc.py Builds the company site into site/
src/build.py        Builds the Nexora product site into site/nexora/
src/audit.py        Dev check: flags uneven column heights across both sites
site/               Everything that gets served. Nothing else is public.
```

Build sources live outside `site/`, so they are never served.

## Building

```sh
python3 src/build_nibarc.py   # company site  -> site/
python3 src/build.py          # Nexora        -> site/nexora/
python3 src/audit.py          # optional layout check
```

Both scripts fingerprint their own assets (`name.<sha256[:8]>.ext`) and rewrite
the references in their own HTML. They do not touch each other's output.

## Asset caching

`netlify.toml` serves `/assets/*` and `/nexora/assets/*` with a one-year
`immutable` cache. That is only safe because every asset filename carries a
content hash — change a file and it ships at a new URL. **Never** add an
unfingerprinted file under either `assets/` directory, and never loosen the
fingerprinting without also relaxing that header. Icons keep stable names and
are deliberately capped at one hour.

## Brand

Nibarc: Archivo / Inter / IBM Plex Mono; graphite `#0A0E12`, jade `#0E8F82`
(`#3AD6C4` on dark). The mark is a rising arc with a jade terminus —
`site/assets/brand/mark.svg`.

Nexora keeps its own identity as the product brand: Fraunces / Manrope /
JetBrains Mono, ink `#0F172A`, paper `#FAFAF7`, seal `#8A1C3B`.

## Screenshots

Product screenshots use fictional demonstration data (Suncrest Juice Co. and
Meridian Foods). No real customer, person, project or system appears anywhere
on either site. Keep it that way when swapping screens — see the anonymisation
note in `src/build.py`.

## Previewing locally

Double-click `serve.command`, or:

```sh
cd site && python3 -m http.server 8787
```

Serve from `site/`, not the repo root — the pages use absolute paths (`/assets/...`,
`/about/`), which is what Netlify serves. Opening `site/index.html` straight from
Finder (`file://`) will not work for the same reason.
